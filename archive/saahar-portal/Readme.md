# Saahar-Link ✦

Smart Urban & Civic Community Connectivity Gateway.

Saahar-Link bridges urban resources, public services, transport, and community networks into one unified digital portal for citizens and municipalities.

## 🚀 Features

- **Integrated Urban Services**: Centralized portal for Healthcare, Smart Transit, EV Infrastructure, and Municipal Care.
- **Real-time Live Bulletin**: Instant civic alerts on transit schedules, utility maintenance, and neighborhood announcements.
- **Search & Quick Categorization**: Live filtering and search across civic services.
- **Adaptive Dark / Light Mode**: Seamless theme switching with persistent user preferences.
- **Direct Citizen Inquiry**: Rapid connection to ward coordinators and municipal desks.

## 💻 Tech Stack

- **HTML5 & CSS3**: Vanilla modern CSS with glassmorphic cards, responsive flex/grid layouts, and sleek typography.
- **JavaScript (ES6+)**: Zero-dependency client-side interactivity, live search filters, and metric animations.

## 🌐 Deploy to Vercel

1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository (`Shahidkhan-0708/Saahar-link`).
4. Click **Deploy**. Vercel will immediately deploy the static application with a live `.vercel.app` URL.
